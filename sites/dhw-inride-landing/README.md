# DHW-inRide landing page

Static, responsive marketing page for the motorbike-only DHW-inRide service in
Chongwe, Zambia.

## Preview locally

Open `dist/index.html` in a browser, or serve the `dist` directory with any
static HTTP server.

The App Store and Google Play buttons intentionally show a "coming soon"
message until real store listing URLs and a verified release are available. The
page must not be treated as evidence that live tracking, hosted trips, or public
operations are available.

## Files

- `dist/index.html` — semantic page structure and content
- `dist/styles.css` — responsive design and animations
- `dist/script.js` — reveal effects and store-button status messages
- `dist/assets/dhw-inride-hero.jpg` — supplied DHW-inRide reference artwork
